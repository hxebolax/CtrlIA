# Novedades de MiAplicacion

Cada versión tiene su apartado, de la más reciente a la más antigua. Dentro de cada versión, los cambios se agrupan en Novedades, Mejoras y Correcciones. Se describen con palabras de quien usa la aplicación: qué puede hacer ahora y dónde, no cómo está programado.

## Versión 1.1.0 - 2026-10-15

### Novedades

- Puede buscar dentro del manual con Ctrl+F. F3 va al siguiente resultado.

### Mejoras

- El lector de pantalla anuncia el número de elementos al abrir una lista.

### Correcciones

- Al cerrar las preferencias con Escape ya no se pierden los cambios guardados antes.
